## 2. Какие данные мы собираем

### 2.1. Вы предоставляете сами

| Данные | Когда собираются |
|---|---|
| Номер телефона (+998…) | Регистрация, вход, восстановление пароля |
| Пароль (хранится на сервере в виде хеша) | Регистрация, вход |
| Код подтверждения из SMS | Подтверждение номера, сброс пароля |
| Имя, фамилия, пол, год рождения | Заполнение профиля (по желанию) |
| Фото профиля (аватар) | Заполнение профиля (по желанию) |
| Email | Заполнение профиля или вход через Google |
| Название, тип, телефон, режим работы и описание бизнеса | Добавление бизнеса |
| Фотографии бизнеса и объявлений | Добавление бизнеса/объявления |
| Адрес филиала и его координаты на карте | Добавление филиала |
| Текст обращения | Обращение в поддержку |

### 2.2. При входе через Google

Если Вы выбираете вход через Google, Google передаёт нам Ваш **email, имя и фото профиля**.
Мы не видим и не получаем Ваш пароль от Google.

### 2.3. Данные о местоположении

Для отметки филиала на карте Приложение может запросить текущее местоположение устройства
(разрешения на примерное и точное местоположение). Это **необязательно**: без разрешения
адрес можно выбрать на карте вручную. Разрешение можно отозвать в настройках устройства
в любое время. Мы не отслеживаем местоположение в фоновом режиме.

### 2.4. Технические данные

Для работы и безопасности сервиса: токен сессии, тип и версия приложения и устройства,
технические записи об ошибках, время запроса и IP-адрес.

Мы **не собираем данные платёжных карт**.

## 4. Кому раскрываются данные

Мы **не продаём** Ваши данные. Передача возможна только:

- **Google LLC** — для работы входа через Google;
- **SMS-провайдер** ([название]) — для отправки кода подтверждения;
- **Хостинг-провайдер** ([название, регион]) — для хранения данных;
- **Картографический сервис** ([название]) — для отображения точки филиала;
- **Приложение для студентов** — название, тип, филиалы, режим работы, фотографии бизнеса
  и условия скидки **видны студентам публично**. Ваш личный номер телефона и email в
  объявлении не показываются (кроме контактного номера, указанного для бизнеса);
- **Уполномоченные государственные органы** — по законному запросу.

Данные хранятся на серверах, расположенных [указать — например: на территории Республики

- **Бухгалтерские и иные записи, требуемые законом** — в установленные законом сроки;
- **Технические журналы (логи)** — до [90] дней.

Вы вправе:

## 8. Безопасность

- Обмен с сервером шифруется по HTTPS;
- Пароли не хранятся в открытом виде (одностороннее хеширование);
- Токен сессии хранится в защищённом хранилище устройства;
- Доступ сотрудников к данным ограничен служебной необходимостью.

Ни один сервис не может гарантировать 100% защиту, однако мы применяем разумные технические
и организационные меры.

## 9. Дети

несовершеннолетнего, они будут удалены.
